# BRAXIL Plugins

Official plugin registry for [BRAXIL](https://braxil.ai) — the desktop agent
runtime behind `koi-cli` and the Braxil Mac/Windows/Linux apps.

A plugin is a self-contained package that extends the agent: new tools,
skills, workflows, MCP integrations, model adapters, or UI affordances.
This repo collects the first-party plugins maintained by the Braxil
team, and serves as the reference layout for community plugins.

## Status

Bootstrapping. Concrete plugins, schema, and install/registry tooling
land here as the platform stabilises.
